# 姜言 iOS · 接入自建 aevis 后端

云端四端（企业微信 / 微信 BOT / iOS / QQ）共用同一套若依后端。

| 用途 | 地址 |
| --- | --- |
| 模型兼容层（OpenAI 协议） | `https://ai.aevis.cn/v1` |
| 账号 / 订单 / 备份码 | `https://aevis.cn` |
| 网页版充值 | `https://aevis.cn/#/wallet` |

## 令牌从哪来

登录网页版后打开「我的 → API 密钥」，或让管理后台生成。
每个账号一把 `sk-` 开头的 Key，**计费按账号走**，跟企业微信那边同账。

## 备份码（转移账号）

1. 老设备：App 内「导出备份码」→ 得到 `ABCD-1234` 这样的码
2. 新设备：登录同一账号 → 「输入备份码」→ 日记 / 记忆 / 周期记录整体搬过来

备份码 30 天内有效，只能被认领一次。
